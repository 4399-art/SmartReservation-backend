# 座位预约规则
1. 登录后打开区域空间列表，选择心仪的区域和座位，填写日期和时段后提交。
2. 提交后状态为待审核，管理员通过后才能使用。
3. 待审核、已通过的预约，本人可以取消；已拒绝的不能取消。
4. 未指定具体座位时，系统将为您在该区域自动分配。

# 图书馆开放时间
- 社科阅览室、自然科学阅览室、电子阅览室：周一至周日 08:00-22:00
- 自习室：周一至周日 06:00-23:00（24 小时开放备考专区）
- 讨论室：周一至周日 09:00-21:00
- 报刊阅览区：周一至周日 08:00-20:00
开放时间内仍需先预约并审核通过，不能直接进入。

# 图书馆使用规范
1. 保持安静，禁止大声喧哗、接打电话。
2. 禁止把零食带入阅览区域。
3. 爱护座位和设备设施，发现损坏及时联系管理员。
4. 离开时请关闭电源（如有），整理好桌面，将椅子归位。
5. 禁止占座超过 30 分钟，超时未到视为自动放弃。

# 座位使用说明
- 带电源座位：适合使用笔记本电脑，请自备充电器。
- 带 USB 插座座位：可直接给手机等小型设备充电。
- 自习室座位：24 小时开放，备考同学优先。
- 讨论室：需要小组讨论请预约讨论室，请勿在普通阅览区讨论。
- 预约座位后请按时到馆，迟到 30 分钟以上预约自动失效。
