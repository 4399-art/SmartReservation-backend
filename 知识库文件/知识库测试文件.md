# 实验室预约规则
1. 登录后打开实验室列表，选择实验室或设备，填写日期和时段后提交。
2. 提交后状态为待审核，管理员通过后才能使用。
3. 待审核、已通过的预约，本人可以取消；已拒绝的不能取消。

# 实验室开放时间
- 计算机实验室：周一至周五 08:00-21:00，周末 09:00-17:00
- 化学实验室：周一至周五 08:30-18:00，周末不开放
- 物理实验室：周一至周日 08:00-20:00
开放时间内仍需先预约并审核通过，不能直接进入。

# 实验室安全规范
1. 进入实验室须穿实验服，化学实验室须戴护目镜。
2. 禁止把零食带进化学实验室。
3. 设备损坏应立即停用，并联系实验室管理员，不要自行拆修。
4. 离开前关闭电源、水源，清理台面。

# 设备使用说明
- 预约设备时必须同时选择所属实验室。
- 电子显微镜使用前先检查镜头和样品台，结束后填写使用登记。
- 设备与实验室绑定：约了设备，时段内实验室也占用。
