# 智慧图书馆智能助手使用指南

## 助手简介

智慧图书馆座位预约助手是基于 LangGraph Agent 构建的智能问答与预约助手，集成了工具调用（Tool Calling）和检索增强生成（RAG）能力。用户可以通过自然语言完成座位查询、预约、取消等操作，也可以咨询图书馆的规章制度。

## 核心能力

### 1. 区域与座位查询

助手可以查询图书馆各区域空间和座位的实时状态：

- 列出所有开放的区域："帮我看看有哪些开放的区域"
- 查询某个区域详情："自习室有多少座位"
- 查看指定区域的座位列表："电子阅览室的座位"
- 检查某个时段是否可预约："明天下午自习室有空位吗"

### 2. 智能预约

用户只需用自然语言说清楚意图，助手会自动完成预约：

**示例对话**：
```
用户：帮我预约明天下午自习室的座位
助手：好的，请问具体哪个时段？比如 14:00-16:00
用户：14:00-16:00
助手：✅ 预约创建成功！
预约ID: 12
区域: 自习室
时间: 2026-10-06 14:00~16:00
状态: 待审核
```

**预约要点**：
- 用户必须给出具体时段（如 14:00-16:00），模糊词"下午"、"上午"会被追问
- 日期可以说"明天"、"周五"、"下周一"，助手会自动转换为真实日期
- 可以指定具体座位编号，也可以只说区域（系统自动分配）

### 3. 我的预约

- 查询自己的预约记录："看看我最近的预约"
- 查询特定状态的预约："我有哪些待审核的预约"
- 取消预约："取消我下午那个自习室的预约"

### 4. 知识库问答

基于 RAG 检索知识库回答图书馆相关问题：

- "图书馆开放时间是什么时候"
- "可以带零食进图书馆吗"
- "占座超过多久会被取消"
- "自习室需要预约吗"

## 工具列表

助手内部调用以下工具完成任务：

| 工具 | 功能 | 说明 |
|------|------|------|
| `list_spaces` | 列出开放区域 | 可按名称/位置搜索 |
| `get_space_detail` | 区域详情+座位列表 | 传入区域 ID |
| `check_seat_availability` | 检查座位可约性 | 需日期、起止时间 |
| `create_reservation` | 创建预约 | 自动带入当前用户 |
| `cancel_reservation` | 取消预约 | 仅本人待审核/已通过的可取消 |
| `list_my_reservations` | 我的预约 | 可按状态筛选 |
| `rag_search` | 知识库检索 | 检索预约规则、规范等 |
| `get_date_info` | 获取当前真实日期 | 避免助手编造日期 |

## 对话技巧

### 让助手更精准
- 说清楚时段："明天 14:00-16:00 自习室" 比 "自习室下午" 更快完成
- 指定具体区域：说"讨论室"、"社科阅览室"比"图书馆"更准确
- 助手会记住上下文，后续可以省略已说过的信息

### 会话管理
- 点击右下角悬浮按钮打开助手窗口
- 默认加载最近一次会话
- 点击左侧 "+" 按钮新建会话
- 会话历史保存在服务器，刷新页面后仍可查看

```
    ↓

```

## 常见问题

**Q: 助手能直接帮我审核预约吗？**
A: 不能。审核是管理员权限，助手只负责帮学生查询和提交预约。

**Q: 助手推荐的座位和实际系统里一样吗？**
A: 是的。助手直接查询数据库，数据完全实时。

**Q: 助手能告诉我哪个座位有电源吗？**
A: 可以。助手会列出座位的详细属性，包括是否带电源、USB 插座等。

**Q: 对话历史会被清空吗？**
A: 手动删除或新建会话时会清空，正常关闭窗口不会丢失。
